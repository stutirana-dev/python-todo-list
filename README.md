# Python To-Do List

A simple command-line To-Do List application built with Python.

## Features

- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Simple interactive menu

## Technologies Used

- Python
- Lists
- Dictionaries
- Functions
- Conditional Statements
- Exception Handling

## Project Purpose

This project was created to practice Python fundamentals and build a simple task-management application.
